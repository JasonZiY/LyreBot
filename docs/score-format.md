# LyreBot text score format, version 0.1

The complete format and transformation protocol now live in the [README's current transformation protocol](../README.md#current-transformation-protocol), which is the review copy for the next revision.

It includes every saved numbered-notation conversion rule alongside the current player's extensions: filenames, tempo, measures, the 21 keys, chords, rests, durations, ties, triplet adaptation, exact fractions, validation, and delivery checks. The README distinguishes saved converter defaults from capabilities already implemented in the player.
