# midi

放 MIDI 文件和录音的地方，LyreBot 会把它们编配成 `txt` 文件夹里的曲谱。

- 放进来的 `.mid` 文件，LyreBot 开着时一两秒后（没开的话下次启动时）编配成「曲名-MIDI」的曲谱。名字以「-录音」结尾、或旁边有同名录音的 MIDI 保留原来的名字。
- 点 ● 录下的音乐存成这里的「曲名-录音.wav」，转成同名的 MIDI 后再编配成「曲名-录音」的曲谱。
- 直接放进来的音频文件也会这样转录：WAV 可以直接转，MP3、FLAC、M4A、OGG 需要电脑上装有 ffmpeg。

已经有对应曲谱的 MIDI 不会再编配，已经有同名 MIDI 或曲谱的音频也不会再转录，所以手改过的曲谱不会被覆盖。想从 MIDI 重新编配，在列表里右键那首曲子，选「从 MIDI 重新编配」。想删掉一首曲子，在列表里右键选「删除」，它的 MIDI 和录音会和曲谱一起移到回收站；只删 `txt` 里的曲谱的话，这里的文件会把它再编配出来。不要把备份或改过的副本放在这里，它们会被当成新的曲子编配一遍。

仓库里只收 MIDI 文件，录音等音频文件留在各自的电脑上，不放进仓库。详细说明见上一层 README 的「从 MIDI 生成曲谱」和「从录音生成曲谱」。
