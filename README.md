# LyreBot

把文本曲谱变成定时的键盘按键，用来在原神等游戏里自动弹琴。只支持 Windows，需要 Python 3.11 或更新版本，不需要安装其他包。

## 使用

1. 双击 `LyreBot.vbs` 启动，不会弹出黑色命令行窗口。LyreBot 会请求管理员权限，点「是」即可：游戏是以管理员身份运行的，LyreBot 也要这样，按键才送得进去。启动不了时改为右键 `Start LyreBot.cmd`、选择「以管理员身份运行」，窗口里会显示报错。
2. 曲目列表就是 `music` 文件夹里的 `.txt` 文件，按拼音排序，改动会自动刷新。右键列表可以打开这个文件夹。写错的曲谱前面有 ⚠，选中后底部会显示错在哪一行。
3. 双击曲目或点 ▶，2 秒内切到游戏并打开琴。倒计时结束时在前台的窗口就是演奏对象。点进度条可以从点击的位置开始演奏，点 ⏭ 演奏下一首。
4. 按 **F8** 或切换到别的窗口，演奏就会停止。演奏时 ■ 按钮是灰的，不用点它，切回 LyreBot 就已经停下了。

游戏里没声音时，先检查输入法是不是英文模式。中文输入法会把字母键当拼音截走。

「速度」按比例缩放整首曲子，包括曲中的变速，可选 80% 到 200%。旁边的选项决定一首弹完以后做什么：「单曲」就停下，「顺序演奏」接着弹列表里的下一首，「随机演奏」随机挑一首，都会一直弹到按 F8 或切换窗口为止。

## 曲谱格式

先看一个例子：

```text
# 第一行之前可以写注释
speed=96
(a.s.d.)-f-g.h.^adg-|z----
s'd-.f.g-0-|x----
speed=>72
q----|^zbn----
```

一行是一个小节，`|` 分开同时演奏的声部。上面这段依次用到了三连音、琶音、倚音、附点和渐慢，下面逐一说明。

### 键位

| 简谱 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 高音（上加点） | q | w | e | r | t | y | u |
| 中音 | a | s | d | f | g | h | j |
| 低音（下加点） | z | x | c | v | b | n | m |

用的是键盘上的物理位置，换了键盘布局也不影响。相邻的字母是和弦，`adg-` 就是 1、3、5 同时按。`0` 是休止符。

### 时值

时值写在音符后面，以四分音符为一拍，几个符号连写时**直接相加**。

| 符号 | 拍数 | 对应简谱 |
| --- | --- | --- |
| `-` | 1 | 四分音符（不加线） |
| `.` | 1/2 | 一条下划线 |
| `~` | 1/4 | 两条下划线 |
| `*` | 1/8 | 三条下划线 |
| `{n/d}` | n/d | 任意精确拍数，如 `{1/3}`、`{2}`、`{3/2}` |

所以 `a--` 是二分音符，附点四分是 `a-.`，附点八分是 `a.~`。花括号可以和符号混用，`a-{1/3}` 就是一又三分之一拍。

每个音符、和弦、休止符后面都必须写时值，时值本身也起分隔作用：`asd-` 是一个和弦，`a-s-d-` 是三个音。

### 小节、声部与延音

- 同一行里每个声部的总拍数必须相等，否则会报错并指出是哪一行。这能拦住大部分抄谱错误。
- 整首曲子的声部数量要一致，数量本身不限。
- 行首直接写时值，表示把这个声部的上一个音继续延长，不会重新按键。简谱里跨小节的延音线就这样写：

```text
speed=100
a----|z----
--s--|x----
```

`a` 一共响 6 拍，第二行只在第 3 拍按一次 `s`。

行中间需要延音时，用 `+` 加时值：`+-` 表示把前一个音再延长 1 拍，不重新按键。比如三连音的最后一个音连到下一拍，写成 `(d.s.d.)-+-`。`+` 放在行首时，和直接写时值的效果一样。

### 连音组

用括号把一组音包起来，括号后面写**整组一共占几拍**。组内按各自写的时值比例平分这段时间。

| 写法 | 含义 |
| --- | --- |
| `(a.s.d.)-` | 八分三连音，三个音平分 1 拍 |
| `(a-s-d-)--` | 四分三连音，三个音平分 2 拍 |
| `(a~s~d~f~g~).` | 五连音，五个音平分半拍 |
| `(a-s.)-` | 不等分，`a` 占 2/3 拍，`s` 占 1/3 拍 |
| `(a-(s.d.f.)-)-` | 可以嵌套 |

抄谱时组内照着简谱原样写（三连音写成三个八分音符），括号外写简谱上这组实际占的拍数即可。组内可以有和弦、休止符和装饰音。

### 琶音与倚音

| 写法 | 含义 |
| --- | --- |
| `^adg-` | 琶音，按书写顺序从左到右依次弹，每个音间隔 30 毫秒 |
| `^gda-` | 反过来从高往低刷 |
| `s'a-` | 倚音：先弹 `s`，60 毫秒后弹主音 `a` |
| `d's'a-` | 连着两个倚音 |
| `sd'a-` | 倚音也可以是和弦 |
| `s'^adg-` | 倚音后接琶音 |
| `e^bfj-` | `e` 不在琶音里，和琶音的第一个音 `b` 同时弹 |

装饰音占用的是主音自己的时间，不改变拍子。间隔用毫秒而不是拍数，因为刷琴的手速不随曲速变化。如果装饰音会占掉一个短音符一半以上的时间，就按比例压缩。

两个间隔可以在曲谱中修改，从这一行往后生效：

```text
roll=50
grace=40
```

### 速度与变速

| 写法 | 含义 |
| --- | --- |
| `speed=120` | 从这里开始每分钟 120 拍 |
| `speed=120>80` | 从这里由 120 渐变到 80 |
| `speed=>80` | 从当前速度渐变到 80 |

`speed=` 单独占一行，放在两个小节之间。第一个小节之前必须先有一个。渐变在下一个 `speed=` 出现的位置到达目标速度，后面没有的话就在曲子结尾到达。简谱里常见的写法：

```text
speed=100
...
speed=>70     # rit. 开始
...
speed=100     # a tempo，回到原速
```

渐变是按拍数线性改变 BPM 的，同一位置写了两个 `speed=` 时以后一个为准。

### 其他

- `#` 之后到行尾都是注释，空行和空格会被忽略。
- 文件用 UTF-8 编码，最大 2 MiB。
- 每次按键是 35 毫秒的轻点，记下的时值只决定什么时候按。同一个键连续很快时，会自动缩短按住的时间，保证两次之间松开过。几个声部同时按同一个键，只按一次。

## 从 MIDI 生成曲谱

把 `.mid` 文件拖到 `Arrange MIDI.cmd` 上，`music` 文件夹里就会多出同名的 `.txt` 曲谱。已有同名文件时不会覆盖，而是另存为「名字 (2).txt」。也可以在命令行运行：

```text
python -m lyrebot.arrange 歌曲.mid
```

网上的 MIDI 大多是完整编制，直接逐个音映射到琴键上只会乱弹，所以这里会先编配，步骤如下。

1. 按「音轨 × 通道」把 MIDI 分成若干部分。鼓（第 10 通道）和音效不参与。
2. 自动挑出旋律所在的部分：音偏高、大多一次只有一个音、贯穿全曲，或者名字像旋律（melody、vocal、右手等）。取它最高的那条线当旋律，其余所有音里最低的那条线当低音线。钢琴这种左右手在同一轨的部分，右手一休息，最高线就会落进左手，所以比前后两拍的旋律低一个八度以上的音会还给伴奏。旋律整小节休息时，借用其余部分（低音线以外）最高的那条线补上。
3. 整体移调，让尽量多的音落在白键上。小调的曲子会落在 A 小调；五声音阶的曲子落在 C、D、E、G、A 上，和简谱的写法一致。
4. 旋律逐小节选择八度，尽量放在中、高两排。八度叠奏的前奏这类整段偏高或偏低的段落会整段移动，零星超出音域的音才单独折回。低音线整条一起放进低、中两排（最高到 B4），保住起伏。仍在黑键上的音改到相邻的白键，并在那个小节末尾注明，如 `# 改动 ♯5→g`。
5. 打谱软件导出的 MIDI 保留原来的拍点，三连音、五连音也照写；演奏录制的 MIDI 按拍量化到十六分音符或三连音。一拍里混着互不相干的细分时（手工摆放的花音、刮奏），这一拍按 32 分音符对齐。每行一个小节，按 MIDI 里的拍号划分；速度变化放在小节线上。

生成的曲谱目前只有旋律和低音线两个声部，伴奏的和弦还不会重新编写，生成后请先试听再按需修改。自动判断不对时，先列出各部分看看：

```text
python -m lyrebot.arrange 歌曲.mid --list
```

再用 `--melody 2` 指定旋律所在的部分（可以写多个，如 `2,3`），`--drop 4,5` 去掉不要的部分，`--transpose -3` 手动指定移调的半音数。

## 开发

```text
lyrebot/score.py     曲谱解析，全部用精确分数计算拍数
lyrebot/timeline.py  拍数 → 秒 → 按下/松开事件
lyrebot/player.py    按时钟演奏，检查 F8 和前台窗口
lyrebot/keyboard.py  Windows SendInput，物理扫描码
lyrebot/app.py       界面
lyrebot/midi.py      读取 MIDI 文件，只用标准库
lyrebot/arrange.py   把 MIDI 编配成诗琴曲谱
```

运行测试：

```text
python -m unittest discover tests
```
