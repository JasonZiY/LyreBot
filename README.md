# LyreBot

把文本曲谱变成定时的键盘按键，用来在原神等游戏里自动弹琴。也可以从 MIDI 文件、录音或自己的演奏生成曲谱，或者把曲谱导出成简谱。只支持 Windows，需要 Python 3.11 或更新版本，不需要安装其他包。从录音生成曲谱还要另外下载免费的 audio.cpp 和 MuScriptor 模型，见「从录音生成曲谱」。

## 使用

1. 双击 `LyreBot.vbs` 启动，不会弹出黑色的命令行窗口。LyreBot 会请求管理员权限，点「是」即可：游戏以管理员身份运行，LyreBot 也要以管理员身份运行，按键才能送进游戏。启动不了时，改为右键 `Start LyreBot.cmd`，选择「以管理员身份运行」，窗口里会显示报错。
2. 列表里的曲目就是 `txt` 文件夹里的 `.txt` 曲谱，同一组里按拼音排序，文件改动后列表会自动刷新。`txt/OST/地区名` 里的曲谱归到 OST 的对应地区，`txt/歌曲` 里的归到歌曲，其余都是未归类，显示在最上面。打开时只展开 OST，各地区和歌曲都是收起的，点名字展开，曲子分两列排在下面；名字后面的数字是里面有几首曲子。右键曲子选「移到…」，可以把它挪到别的地区、歌曲或未归类。在顶上的搜索框里输入曲名中的字，点「搜索」或按回车，会跳到第一首名字里有这些字的曲子，再点一次跳到下一首，到底后从头再来。新生成的曲谱放在 `txt` 里，也就是未归类，想归到哪里自己挪进去。写错的曲谱前面有 ⚠，选中后底部会显示错在哪一行。
3. 双击曲目或点 ▶，然后在 2 秒内切到游戏并打开琴。倒计时结束时在前台的窗口就是演奏对象。也可以先在游戏里打开琴，再按 **F7**：不用倒计时，立刻对着当前窗口弹选中的曲子。只要 LyreBot 开着，F7 在哪个窗口里按都算，所以别在打字的窗口里按。点进度条可以从点击的位置开始演奏，点 ⏭ 演奏下一首。
4. 按 **F8** 或切换到别的窗口，演奏就会停止。演奏时 ■ 按钮是灰的，不用点它：切回 LyreBot 的时候演奏就已经停了。被打断的曲子会记下停在第几小节，之后点 ▶ 或按 F7，就从那一小节的开头接着弹；点 ▶ 左边的 ↺ 则从头弹。换了曲子或点了进度条，就不再接着弹。

游戏里没有声音时，先检查输入法是不是英文模式：中文输入法会把字母键当成拼音截走。

「速度」按比例缩放整首曲子，包括曲中的变速，可选 80%、100%、120%、150% 和 200%，也可以点「自定义…」填 25% 到 300% 之间的任意数值。旁边的选项决定一首弹完以后做什么：「单曲」就此停下，「单曲循环」从头再弹这一首，「顺序演奏」接着弹同一个播放列表的下一首，「随机演奏」在这个播放列表里随机挑一首，后三种会一直弹到按 F8 或切换窗口为止。OST 和歌曲是两个播放列表：OST 顺序演奏时先弹完本地区，再去下一个地区，随机时在整个 OST 里挑。未归类的曲谱不属于任何播放列表，只能单曲或单曲循环。

曲谱也可以不手写：把 MIDI 文件放进 `midi` 文件夹，LyreBot 会自动编配成「曲名-MIDI」的曲谱加进列表（见「从 MIDI 生成曲谱」）；点 ▶ 左边的 ●，可以把电脑正在播放的音乐录下来，同样编配成曲谱（见「从录音生成曲谱」）；● 左边的键盘按钮会把你在游戏里弹的琴记成曲谱（见「记录演奏」）。右键曲子可以把它移到别处、按 MIDI 重新编配、导出成简谱（见「导出简谱」）或删除；右键 OST、歌曲或地区名会打开对应的文件夹，右键列表下面的空白处打开 `txt` 文件夹。

删除（右键选「删除」，或选中后按 Delete）把文件移到回收站，需要时可以从回收站还原，删之前会列出要删的文件。手写的曲谱和「曲名-演奏」只删曲谱本身；从 MIDI 或录音编配的曲谱（「曲名-MIDI」「曲名-录音」，以及第一行写着由哪个 MIDI 编配的曲谱）连同 `midi` 文件夹里的那个 MIDI 和同名录音一起删，不然 LyreBot 一两秒后又会从它们生成一份。导出到 `jianpu_output` 的同名简谱也一起删。

## 手写曲谱

曲谱是普通的文本文件，一行一个小节，用键盘字母写音，用符号写时值，比如 `a-` 是中音 1 弹一拍，`|` 分开同时演奏的声部。键位、时值、连音、琶音、倚音和变速的写法见 [曲谱格式](docs/曲谱格式.md)。

## 从 MIDI 生成曲谱

把 `.mid` 文件放进 `midi` 文件夹，LyreBot 开着时一两秒后、没开时下次启动时，就会在 `txt` 文件夹里生成曲谱，并在列表里选中它。`飞鼠进行曲.mid` 编出来的曲谱叫「飞鼠进行曲-MIDI」，和录音转出来的「曲名-录音」、键盘记下来的「曲名-演奏」区分开；录音转成的 MIDI（旁边有同名的录音，或者名字以「-录音」结尾）沿用原来的名字。编配时不会演奏，演奏时也不会编配。

已经有同名曲谱（或者叫「曲名-MIDI」的曲谱）的 MIDI 不会再编配，曲谱放在 `txt` 里哪个文件夹都算，所以手改过的曲谱不会被覆盖。曲谱的第一行写着它是从哪个 MIDI 编配的，所以改名或挪进别的文件夹以后，也不会再从这个 MIDI 生成一份旧名字的曲谱。想按 MIDI 从头再来，在列表里右键那首曲子，选「从 MIDI 重新编配」，确认后会覆盖原来的曲谱。编配失败的 MIDI 只提示一次，换一份同名文件进去会再试。

编配时会自动挑出旋律、移调并重写伴奏。和弦是按音高猜出来的，可能猜错，生成后请先试听，再按需修改。自动判断不对时可以用命令行手动指定，参数见 [手动调整](docs/原理与开发记录.md#手动调整)，编配的步骤见 [从 MIDI 编配](docs/原理与开发记录.md#从-midi-编配)。

## 从录音生成曲谱

点 ▶ 左边的 ●，填上曲名（录音和曲谱都叫「曲名-录音」，不填就按时间起名），然后在别处播放想编配的音乐，视频网站、音乐软件、游戏里的背景音乐都可以。LyreBot 录的是电脑扬声器正在播放的声音，所以开始前先关掉其他声音。有声音时才开始录（等 5 分钟还没有声音就不录了），点 ■、安静 5 秒或录满 10 分钟时结束。

录完以后，录音存成 `midi` 文件夹里的「曲名-录音.wav」，再由 MuScriptor 模型转成同名的 MIDI，最后照上一节的方法编配成 `txt` 里的曲谱并选中它。转录在后台进行，不影响演奏；演奏时不会开始新的转录。也可以直接把音频文件放进 `midi` 文件夹：WAV 可以直接转，MP3、FLAC、M4A、OGG 需要电脑上装有 [ffmpeg](https://ffmpeg.org/)。已经有同名 MIDI 或曲谱的音频不会再转。

录音转出来的曲谱只求弹起来和原曲一样，节拍和小节线不一定规整。钢琴独奏转得最好，配器复杂的曲子（乐队、电子乐）只能当作手改的底稿，转完先听一遍。转录是怎么做的、准确度如何，见 [转录录音](docs/原理与开发记录.md#转录录音)。

### 准备转录工具

转录要用到 [audio.cpp](https://github.com/0xShug0/audio.cpp)（Apache-2.0 许可证）和 MuScriptor 模型（CC BY-NC 4.0 许可证，只能用于非商业用途），LyreBot 没有自带。三个文件一共约 1.3 GB，都不用登录就能下载。一步一步的装法、怎么检查装好了、常见的报错，见 [从录音生成曲谱-安装说明](docs/从录音生成曲谱-安装说明.md)。

## 记录演奏

点 ● 左边的键盘按钮，填上曲名（曲谱叫「曲名-演奏」，不填就按时间起名），然后切到游戏，打开琴照常弹。LyreBot 在后台记下你按的每一个琴键和按下的时刻；弹完按 **F8**、切回 LyreBot 点 ■，或者 30 秒不弹，就把记下的按键写成 `txt` 文件夹里的曲谱并选中它（5 分钟内一个琴键都没按就不记了，最长记 30 分钟）。只记 21 个琴键；按着 Ctrl、Alt 或 Win 时按的键、LyreBot 自己的窗口在前台时按的键都不算；按住不放的键只算一次。别的程序模拟出来的按键也会记下，所以别的自动弹琴工具弹的曲子同样能记成曲谱。

写谱的目标只有一个：用 LyreBot 弹回去时，每个键按下的时刻都和你弹的一样。选中这份曲谱时，底部会显示有百分之几的按键在 0.05 秒内照原样弹回。手越稳，写出来的曲谱越整齐。写谱的方法和测试结果见 [记录演奏](docs/原理与开发记录.md#记录演奏)。

## 导出简谱

在列表里右键一首曲子，选「导出简谱」，就会在 `jianpu_output` 文件夹里生成同名的网页，并用浏览器打开。想要 PDF，在浏览器里打印，选「另存为 PDF」即可。导出的简谱只存在自己电脑上的 `jianpu_output` 文件夹里，不放进仓库，随时可以重新生成。

录音编出来的和键盘记下来的曲谱，导出时节奏会整理得便于阅读，右上角有注明，演奏仍以曲谱为准，曲谱本身不会改。版式和各类曲谱的导出方式见 [导出简谱](docs/原理与开发记录.md#导出简谱)。

命令行也可以导出，可以一次给多个曲谱：

```text
python -m lyrebot.jianpu txt/OST/枫丹/柔灯轻漾时.txt
```
