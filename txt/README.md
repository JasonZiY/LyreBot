# txt

LyreBot 的曲谱都在这里。这里的每个 `.txt` 文件是列表里的一首曲子，按拼音排序，文件改动后列表会自动刷新。

`txt` 下面一层的文件夹（现在是 `OST` 和 `其他`）在列表里是可以展开、收起的分组，曲谱放进哪个文件夹就出现在哪一组；再往下一层的文件夹不算。LyreBot 新生成的曲谱直接放在 `txt` 里，排在各组后面，想归到哪一组自己挪进去即可。

文件名的后缀表示曲谱的来源：

| 名字 | 来源 |
| --- | --- |
| 曲名 | 照简谱手写 |
| 曲名-MIDI | 由 `midi` 文件夹里的 MIDI 文件编配 |
| 曲名-录音 | 由录音转成 MIDI 再编配 |
| 曲名-演奏 | 由键盘记下的演奏写成 |

自动生成的曲谱第一行写着它的来源，如 `# 由 MIDI 自动编配：曲名.mid`、`# 由键盘演奏记录：曲名-演奏`。改名或挪到别的文件夹时请保留这一行：LyreBot 靠它知道这个 MIDI 已经编配过，不会再生成一份旧名字的曲谱。

曲谱的写法见上一层 README 的「曲谱格式」。这些曲谱一部分转写自 <https://space.bilibili.com/76052941> 发布的诗琴简谱，其余来自公开的音频和乐谱资源。乐曲和编曲归各自的作者所有，不在代码的 MIT 许可证之内。
