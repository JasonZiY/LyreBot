# txt

LyreBot 的曲谱都在这里。这里的每个 `.txt` 文件是列表里的一首曲子，同一组里按拼音排序，文件改动后列表会自动刷新。

放在哪里决定它在列表里的位置。`OST` 下面按地区分文件夹（蒙德、璃月、稻妻、须弥、枫丹、纳塔、挪德卡莱、至冬、夏日、其他），`歌曲` 是另一组，这两组各是一个播放列表。直接放在 `txt` 里的是未归类，显示在最上面，只能单曲演奏。LyreBot 新生成的曲谱也放在这里，想归到哪一组自己挪进去即可。

文件名的后缀表示曲谱的来源：

| 名字 | 来源 |
| --- | --- |
| 曲名 | 照简谱手写 |
| 曲名-MIDI | 由 `midi` 文件夹里的 MIDI 文件编配 |
| 曲名-录音 | 由录音转成 MIDI 再编配 |
| 曲名-演奏 | 由键盘记下的演奏写成 |

自动生成的曲谱第一行写着它的来源，如 `# 由 MIDI 自动编配：曲名.mid`、`# 由键盘演奏记录：曲名-演奏`。改名或挪到别的文件夹时请保留这一行：LyreBot 靠它知道这个 MIDI 已经编配过，不会再生成一份旧名字的曲谱。

曲谱的写法见 [曲谱格式](../docs/曲谱格式.md)。这些曲谱一部分转写自 <https://space.bilibili.com/76052941> 发布的诗琴简谱，其余来自公开的音频和乐谱资源。乐曲和编曲归各自的作者所有，不在代码的 MIT 许可证之内。
